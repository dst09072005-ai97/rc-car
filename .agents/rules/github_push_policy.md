# Quy tắc Bảo vệ GitHub (Strict GitHub Push Policy)

- **TUYỆT ĐỐI CẤM** tự ý chạy `git push` lên GitHub trong mọi hoàn cảnh.
- Kho GitHub (`origin/main`) là bản backup an toàn của người dùng.
- Mọi thao tác phát triển, tối ưu, refactor chỉ thực hiện và commit tại local.
- **CHỈ ĐƯỢC PHÉP PUSH** khi người dùng gõ xác nhận rõ ràng bằng lời (ví dụ: "tôi xác nhận, hãy push lên github", "confirm push all").
