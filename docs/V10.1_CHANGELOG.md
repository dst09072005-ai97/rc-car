# V10.1.0

- Fixed Godot 4.7 GDScript `Vector2` vs `Vector2i` parse error.
- Fixed ambiguous type inference for throttle acceleration flag.
- Removed unused/invalid hand-tracking export settings from the Android preset.
- Switched Android V10.1 preset to pre-built export templates instead of Gradle build by default.
- Added `setup_android.cmd` to configure Godot 4.7 per-user Android SDK/JDK settings and optionally install documented SDK packages.
- Added `check_android.cmd` for environment/template diagnosis.
- `build_android.cmd` now performs a GDScript parse check before export.

## Why pre-built template for V10.1?

The immediate goal is a debug APK for Quest. A Gradle project template is not necessary unless the app needs custom Java/Kotlin/Android plugin integration. Keeping the first V10 native viewer on the pre-built export path reduces moving parts.
