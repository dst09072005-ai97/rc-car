# Third-party components

V10 does not vendor third-party source blobs by default.

## Runtime / build dependencies

- Godot Engine 4.7.x
- Godot OpenXR Vendors (optional), MIT for project sources where applicable; vendor-specific components retain their own licenses
- Node.js
- Express
- ws
- qrcode

Refer to each upstream project for its exact license/version.

The V0 firmware code is carried from the user's supplied V0 archive as the known-good baseline. No closed Meta runtime binary is included in this ZIP.
